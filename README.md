Лендинг для клиента **Grigo Vaster** (заказ пришёл через Бота Буратинова, Telegram, 15.09.2026).
Дизайн-референс из ТЗ — **aviasales.ru**: та же логика блоков, перенастроенная с билетов на банковские продукты.

## Запуск локально


## Как править контент

Всё в `js/data.js`.

- **Добавить оффер** — скопировать блок в `offers`, поменять `id` (латиницей, уникальный), `url`, `erid`.
- **Убрать из «Выбора редакции»** — `pick: false`.
- **Порядок по умолчанию** — поле `popularity` (больше = выше).
- **Быстрые фильтры** — массив `tags` у оффера; список самих фильтров в `D.tags`.

⚠️ `id` менять у уже опубликованного оффера нельзя — по нему строятся id заголовков,
на которые ссылается разметка для скринридеров.

## Что нужно уточнить у клиента

1. **Домен.** Прислан только FTP-логин, пароль и IP. Куда класть сайт — неизвестно.
2. **Название.** «КартСейлс» придумано нами под референс, клиент имя не давал. Меняется в
   `index.html` (логотип, `<title>`, подвал) и в `data.js` → `brand`.
3. **Юрлица рекламодателей.** У каждого оффера есть поле `advertiser` — пустое.
   Заполнить точными названиями из партнёрки, тогда в подписи будет
   «Реклама · ПАО «Банк» · erid: …» вместо «Реклама · erid: …».
4. **Цифры в карточках.** Ставки, лимиты и сроки взяты из публичных описаний продуктов
   и подписаны как справочные. Перед запуском сверить с офферной страницей партнёрки.
5. **Почта в подвале** — сейчас заглушка `info@example.ru`.
6. **Форма подписки** пока без бэкенда: адрес сохраняется в браузере посетителя и
   показывается подтверждение. Если нужны реальные заявки — подключаем `api.php` или бота.

## Доступность

Сайт сделан под WCAG 2.2 AA (в проекте это обязательное требование `CLAUDE.md`).
Автопроверка — 39 сценариев в настоящем Chrome: клавиатура, `Escape` в мобильном меню,
возврат фокуса, объявление количества найденного, сохранение фильтров в адресе,
ошибки формы, размеры кнопок, отсутствие горизонтального скролла на 320 px.

Палитра проверена на контраст:

| Пара | Контраст |
|---|---|
| `#101828` на жёлтом `#ffcc00` | 11,7:1 |
| Обводка кнопки `#8a5a00` к белому | 5,9:1 |
| Белый на синей кнопке `#0b63ce` | 5,7:1 |
| Серый текст `#5a6472` на белом | 6,0:1 |
| Белый на герое `#0b2545 → #0d4f8b` | 15,4:1 → 8,4:1 |

Кольцо фокуса двухцветное (чёрное + белый ореол), поэтому видно и на белом, и на жёлтом,
и на тёмном герое.

## Грабли

- `<dialog>` в панели предпросмотра редактора не закрывается по `Escape`: панель шлёт
  событие с пустым `code`, нативный `cancel` не срабатывает. В настоящем Chrome всё работает,
  плюс в `app.js` есть свой обработчик. Проверять меню только в реальном браузере.
- Не добавлять `overflow-x: hidden` на `html`/`body` — сломается `scroll-padding-top`,
  и липкая шапка начнёт закрывать элемент, на который увели фокус.
- reg.ru кеширует `.js` и `.css` надолго, `.htaccess` на это не влияет.
